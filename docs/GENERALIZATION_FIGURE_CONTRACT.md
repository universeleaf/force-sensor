# 新配置比较图的设计与数据约束

本组图检验 EnFiRCE 在预先固定的通道、末端载荷、杆长及观测密度条件下，是否比项目中的两种曲率基线更准确地分离接触力。结果不预设为正，不宣称官方方法排名。

- 使用现有 Python / matplotlib 后端；7.2 inch 双栏，字体 7–8 pt。输出可编辑 PDF、SVG 和 PNG。
- 四组面板：实际独立真值几何、每个场景的接触向量误差、逐接触力大小、力大小/末端/总力的配对误差比值。各组都覆盖六个配置。
- 每个配置三个独立传感器噪声种子；同尺寸条件使用共同标准噪声。每个种子只有一份输入 MAT，四种方法共用其 SHA。真值在推断后评分。
- 主指标：接触向量 RMSE / N。辅助指标：接触力大小 MAE、末端和总合力 RMSE、接触弧长 RMSE、接触数匹配、复核及退出状态。
- 绘制均值和种子最小/最大范围，显示所有种子点，不把范围称为置信区间。非正退出加空心三角；异常或接触数不匹配明确计数，不能删除后声称全部更优。
- 不做跨论文硬件数值比较，不把现有文献思想适配写成官方复现。no_geometry 只删除接触几何因素，仍保留环境法向及其他完整窗口因素。
- planar 配置采用独立连续 shooting 真值、完整 3-D 逆模型；spatial_sparse 使用旧空间 sliding 真值，改变观测密度。longer_serpentine 是保持几何相似的缩放配置，不能声称形状拓扑变化。
- 几何图仅展示真实求解的两帧，空间样例若作 x-z 投影必须注明；不插值出虚构运动，不生成替代真实运行的视频。
- 图源保留 comparison.json、逐观测/估计文件校验值、source_data.csv、force_data.csv、绘图脚本和 plot_provenance.json。数据未完整记录前不输出最终比较图。
- 审阅：核对坐标和单位、图例/刻度可读性、没有裁掉不利结果；检查 SVG 文本、矢量 PDF 和 PNG。硬件重复、显著性检验、总体 SOTA 和实时性不属于本组图的结论。
