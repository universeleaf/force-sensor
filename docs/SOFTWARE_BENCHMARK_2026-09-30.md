# EnFiRCE 软件实验与基线（2026-09-30）

本页记录目前可以由代码重跑、逐帧核对的多接触实验。它回答两个问题：环境几何能否帮助从稀疏杆形分离多个接触力；平面标定错误、曲率噪声和传感器数量会怎样改变结果。数据全是仿真，尚不能据此宣称达到 SOTA 或具备 RA-L 投稿所需的实验充分性。

## 实验对象与输入边界

`rod/multi_contact_demo_scenes.m` 定义三个固定环境：平行双侧 S 通道、收窄双侧通道、蛇形三接触通道。`rod/build_multi_contact_demo_truth.m` 对每个基座位置求解平面 Cosserat 杆静力平衡，再生成曲率观测；真值力和位置不传给逆解。三个场景分别有 2、2、3 个接触，均为点接触、无摩擦、平面内弯曲。另一个带噪声三接触视频使用相同力学场景，仅供逐帧可视化；正式 benchmark 的噪声在统一协议中重新生成。

主评估使用 3 个噪声种子（11、22、33）、3 个曲率噪声标准差（0、`2.5e-5`、`5e-5 /mm`）、3 个采样密度（8、16、24 个弧长位置）和每个场景的第 3、10 个基座状态。噪声先在 121 个杆节点上用固定种子生成，再对不同采样密度取同一噪声场的子集。每个方法收到完全相同的曲率值、采样弧长、基座位姿、材料刚度和本征曲率。两种方法都知道接触数量与顺序；只有环境方法读取平面位置与法向。总计 396 次估计，全部得到有限数值结果；“完成”不等于通过物理审计。

`rod/estimate_planar_multi_contact.m` 优化基座弯矩、各接触法向力与弧长、独立末端二维力。每次候选都调用 `rod/integrate_planar_multi_contact.m` 计算连续杆形和预测曲率，目标函数将曲率残差按观测标准差白化，并加入自由端弯矩、接触闭合与切触残差。力非负、接触弧长有序；解后由 `rod/audit_planar_multi_contact.m` 检查整杆穿透、端部力矩、闭合、切触及数值秩。这是完整三维摩擦 MAP 的**平面多接触原型**，不能把两者等同。

`rod/estimate_planar_shape_only_point_loads.m` 是同输入的简化基线：先从稀疏曲率积分出杆形，再用弯矩曲线拟合各接触位置的二维点力及末端力。它只使用接触数量，不读平面位置、法向、接触间隙或切触条件。`rod/test_multi_contact_benchmark_protocol.m` 将平面位置和法向大幅改变后验证基线输出不变。基线是本项目实现的“形状加点力”对照，**不是** Xiao、Aloi、Ferguson 或 Prakash 算法的官方复现。

接触力误差是每个接触二维力向量的欧氏误差，再对接触和帧求 RMSE；总力包括全部接触力和独立末端力。下表括号是按 3 个随机种子为簇重采样的描述性 95% bootstrap 区间。每种子只有两个相关状态，区间不应解释为可靠的群体置信区间。
不同方法的 `review` 来自各自的数值/物理检查，不能当成跨方法一致的准确性分类器；误差仍须由离线真值单独计算。

## 主要结果

标称设置（24 个曲率观测，噪声标准差 `2.5e-5 /mm`）共 18 个配对帧：

| 方法 | 接触力 RMSE | 接触弧长 RMSE | 总力 RMSE | 平均求解时间 | review |
|---|---:|---:|---:|---:|---:|
| 环境 + 形状 | 0.490 N [0.424, 0.539] | 0.006 mm | 0.620 N | 1.281 s | 0/18 |
| 仅形状点力 | 2.967 N [2.431, 3.518] | 0.521 mm | 3.764 N | 0.028 s | 0/18 |

环境方法在 17/18 个配对帧上的接触力向量误差更小，但单帧例外确实存在。三个场景分别为：

| 场景 | 环境方法接触力 RMSE | 仅形状基线接触力 RMSE |
|---|---:|---:|
| S 通道双接触 | 0.529 N | 2.505 N |
| 收窄通道双接触 | 0.573 N | 1.986 N |
| 蛇形三接触 | 0.336 N | 4.023 N |

传感器变少会暴露明显的可辨识性问题：标称噪声下，环境方法在 8、16、24 个观测时的接触力 RMSE 分别为 **13.576、0.837、0.490 N**，对应 review 分别为 6/18、0/18、0/18。高噪声 `5e-5 /mm` 下，这三个数为 **15.904、1.813、1.730 N**。8 个观测的结果不适合作为“多接触精确估计”示例。无噪声时接近机器精度的误差只表示真值与逆解共用理想力学模型的数值闭合，不能外推到真实传感器。

## 消融与平面误差

标称设置下，去掉接触闭合惩罚时接触力 RMSE 为 1.169 N；去掉切触惩罚为 1.525 N；两者都去掉为 1.499 N。这些消融仍保留环境法向和基于环境的初值，因此应称为“去掉几何惩罚”，不能称为完全无环境方法。三组消融的 18/18 个结果都触发物理复核标志，说明数值拟合和有效接触解必须分开判断。

把逆解读到的第一个平面沿法向错放 **+1 mm**，而真值和曲率不变时，固定平面模型的接触力 RMSE 从 0.490 N 升到 **31.092 N**，18/18 个结果触发 review。这是项目目前最严重的软件敏感性之一。为此，`rod/estimate_planar_multi_contact.m` 新增 `planePointStdMm`：对每个被使用的平面引入一个共享法向偏移，加入零均值高斯先验，而重复接触同一平面的状态共用一个偏移。该参数没有使用真值，也不会在默认值 0 时改变旧解。

在相同的 18 个错位平面输入上，用预先指定的先验标准差重跑得到：

| 平面处理 | 接触力 RMSE | 总力 RMSE | 第一平面的平均估计修正 | review |
|---|---:|---:|---:|---:|
| 视错位平面为精确 | 31.092 N | 44.259 N | 0 mm | 18/18 |
| 平面偏移先验 SD 0.1 mm | 21.163 N | 29.445 N | −0.283 mm | 18/18 |
| 平面偏移先验 SD 1 mm | 1.341 N | 1.625 N | −1.003 mm | 2/18 |

实际所需的修正为 −1 mm。1 mm 标定先验明显缓解错位，但未恢复到正确几何的 0.490 N，且还有两帧复核标志。先验 SD 是实验设定而非从这些真值帧调出的最佳参数；将来应由独立的相机/平面标定试验确定。

运行时间仅计 MATLAB 逆解函数，不含真值生成、启动、绘图或文件 I/O。环境方法在标称设置下平均约 1.28 s/帧，比仅形状基线慢约 46 倍，也没有达到 20 ms 传感周期。不能称为实时方法。

## 与已发表工作的对应关系

- [Xiao 与 Chen 的局部 FBG 曲率多接触力估计](https://arxiv.org/abs/2109.12469)使用简化 Cosserat 关系和最小二乘，报告接触力大小及位置误差。这里的 shape-only 点力基线只测试相近的信息边界，并未复制其求解器、机器人或数据。
- [Aloi 等的分布载荷估计](https://doi.org/10.1109/LRA.2022.3188905)以沿杆位置观测拟合高斯载荷，在两台腱驱动机器人上做了三维硬件实验。当前通道场景为平面点接触，不具备其分布载荷或硬件条件。
- [Ferguson、Rucker 与 Webster 的连续弧长形状及载荷估计](https://ieeexplore.ieee.org/document/10418521/)包含分布载荷仿真和点载荷硬件验证。仓库 `rod/run_literature_strain_scenarios.m` 仅借用了其杆长、材料及应变噪声等参数测试本项目自己的单接触场景，不是论文实验复现。
- [Prakash、Vela 与 Tsiotras 2026 年的多接触因子图预印本](https://arxiv.org/abs/2606.29165)联合使用应变、腱张力与位姿，并处理未知接触位置和多接触。我们的多接触路径还假设接触数与顺序已知，观测和模型也不同。

另外按当前代码重跑了 `force('literature-strain')`：它把 Ferguson 文中选用的 1 m、1.5 mm 直径、207 GPa 及 10 微应变等**参数**应用于本项目自己的弯曲杆单接触加末端载荷场景。每个密度只有一个噪声种子、一个状态，结果如下：

| 曲率点数 | 环境方法接触力误差 | 本项目 shape-only 误差 | 环境方法 review |
|---:|---:|---:|---|
| 5 | 0.0311 N | 0.0346 N | 是，形状一致性未通过 |
| 15 | 0.0100 N | 0.0155 N | 是，形状一致性未通过 |
| 50 | 0.00781 N | 0.0783 N | 否 |

该协议的[逐条件结果](../out/formulation/literature_strain/comparison.json)和 N5/N15/N50 原始 MAT 位于 `out/formulation/literature_strain/`，不能与多接触表合并，也不能写成对 Ferguson 方法的优势证明。5/15 点结果即便力误差较小，也已经被代码标为需要复核。

因此，当前证据支持“在这三个内部生成、模型一致的平面通道里，环境信息改善了稀疏曲率的多接触力分解”，**不支持 SOTA 结论**。要作公开可比较的 SOTA 主张，必须在相同观测输入、相同真值、相同接触模式定义和相同硬件或公开数据集上运行可验证的原方法实现，并统计失败率、误差分布与速度。现有数据与相关论文中的硬件误差数字不能直接排序。

## 软件实验全局状态与重跑

本页的多接触 benchmark 是新的 396 次逆解和 54 次平面标定敏感性回放。仓库另有已运行的单接触多种子噪声、同观测基线、双接触/非平面/摩擦失配压力测试、Ferguson 参数适配及墙钟性能回放；入口与历史结果分别见 `force.m`、`docs/TECHNICAL_OVERVIEW.md` 和 `out/`。那些旧协议不应与本页多接触误差合并为一个数字。现有失配协议仍以单接触估计器处理双接触真值，主要说明模型边界。

在仓库根目录运行：

```matlab
report = force('multi-benchmark');    % 重建三场景真值、配对噪声和 396 次估计
geometry = force('multi-geometry');   % 重放已保存的标称输入，54 次平面误差估计
smoke = force('multi-benchmark', true); % 少量冒烟输入，写入独立的 smoke/ 目录
```

```text
python scripts/summarize_multi_contact_benchmark.py
```

`rod/run_multi_contact_benchmark.m` 写[逐次比较 JSON](../out/benchmarks/multi_contact/comparison.json)、每场景的 `truth.mat` 与 `trials.mat`；`rod/run_multi_contact_plane_uncertainty.m` 写[平面误差回放 JSON](../out/benchmarks/multi_contact/plane_uncertainty.json)；Python 脚本从这些原始数据生成[完整结果表](../out/benchmarks/multi_contact/summary.md)。JSON 中逐次保留场景、种子、状态、噪声、采样密度、方法、误差、运行时间和 review 标志；MAT 保留每个观测包及解的诊断。这组 benchmark 的上述文件作为精选结果纳入版本库；其他 `out/` 运行目录仍默认忽略。实验依赖 MATLAB R2024a、Optimization Toolbox 和项目已有的本地杆模型依赖。

下一阶段的关键缺口仍是：未知接触数量与模式的搜索、三维摩擦多接触逆解、分布载荷、独立来源的环境与形状标定误差、更多轨迹与随机种子、可公开复用的同输入论文基线，以及实际硬件力真值。它们不是本次运行已经完成的实验。
