# Robust single-pass comparison, 2026-10-25

Compact outputs for [QP_BRANCHES_HISTORY_PRIOR_RESULTS.md](../../../docs/reports/QP_BRANCHES_HISTORY_PRIOR_RESULTS.md). Raw per-trajectory `result.mat`/`frames.csv`/`branches.csv` stay under ignored `results/runs/robust_<stamp>_<config>_s<seed>_<scenario>_<level>mm/` and are regenerated by the commands in the report.

| File | Content |
|---|---|
| `final_pooled.csv` | Held-out seeds 0, 3, 4, 5 (0 mm: seed 0), pooled per scenario/noise/configuration (`summarize_robust.py`) |
| `final_trajectories.csv` | Same metrics per trajectory |
| `tuning_pooled.csv`, `tuning_trajectories.csv` | Tuning seeds 1, 2. `qp_soft_tip0.2_f1_gate` used an FBG-gated prior that was removed from the code after this test |
| `shadow_summary.csv` | fmincon SQP vs profiled QP on identical inputs, seed 0 (`compare_branch_solvers.m`, `summarize_shadow.py`) |
| `named_frames.csv` | Frames named in the 2026-10-13 handoff, all configurations, seed 0 |
| `multicontact_summary.csv` | Recorded 2-3 contact fixtures: reference chain vs QP chain (final code), report Section 8b |
| `multicontact_reference_chain_frames.csv`, `multicontact_qp_chain_frames.csv` | Per-frame scores of both chains (QP columns of the first file are from the earlier single-start search; use the second file) |
| `multicontact_branches_single_start.csv` | Branch objectives on the reference chain's inputs, fmincon vs the earlier single-start QP search (kept for the record) |
| `timing.csv` | Solo single-thread timing per stage, seed 0, 1 mm |
| `plots/final_*_s0.png` | Seed 0 force components and errors: reference, `qp`, `qp_soft_tip0.2_f1` |
| `plots/phase1_rotation_0p5mm_s0_reference_vs_qp.png` | Published-noise 0.5 mm rotation: fmincon vs exact branches |
| `plots/tuning_varying_1mm_s1_prior_lag.png` | Prior bias/lag on the time-varying tip load |

Configuration names are parsed by [robust_configurations.m](../../../experiments/robust_pass/robust_configurations.m): `reference` = unchanged fine-step estimator; `qp` = `singlePassMethod='profiled-qp'`; tokens `trust`, `soft`, `tip<v>`, `f<v>`, `r<v>`, `fast` add the switches defined in [PROFILED_QP_BRANCHES.md](../../../docs/formulation/PROFILED_QP_BRANCHES.md).

Noise: seed 0 is the published `fine_bvp_comparison_20261012_step5/reproduction/noise_payload.mat`; seeds k >= 1 use `rng(1000*k+7,'twister')` standard normal draws of the same size, with the restored rotation state sharing the insertion maximum-insertion draw (`run_robust_suite.m`). Varying-tip trajectories reuse the insertion draws of the same seed. Errors are RMS vector norms over every frame except the restored rotation seed; failures are retained (one reference frame returned a non-finite state and is scored with the held previous estimate).
